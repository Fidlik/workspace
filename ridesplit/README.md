# RideSplit

A simple web app for planning weekly bike trips and splitting shared costs.

## MVP

- Create weekly bike trips with date, start location, and map link
- Let people join a trip
- Upload receipt photos for shared expenses
- Split expenses between selected people
- Generate payment QR codes
- Let each person edit their bank account details

## Hosting Plan

- Cloudflare Pages for the web app
- Cloudflare D1 for app data
- Cloudflare R2 for receipt images
- Cloudflare Workers or Pages Functions for API routes
